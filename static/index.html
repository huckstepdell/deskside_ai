Yes, pasting everything in is cheaper. At this size it is — seven files fit in a prompt with room to spare. Two things to notice anyway. It gets one pass: no re-reading, no cross-checking, no arithmetic it can verify, so compare its findings and its total against the agent's before you trust it. And it only works while the data fits — seven expense reports do, seven hundred don't, and neither does a ticket system, a document repository, or a codebase. The agent decides what to read, so it works the same at any size. That's what the token bill buys, and every loop it runs resends the whole conversation, which is why an agentic workload costs what it costs. The more of your work it does, the bigger that bill gets — which is the argument for owning the silicon it runs on.

Figures price this run's tokens at $3.00 per million in / $15.00 per million out — mainstream frontier API rates, no prompt-caching discount assumed (caching would trim the input side, not change the curve). The point isn't the exact number; it's the slope.

An always-on AI agent, in a sandbox

This box runs NVIDIA NemoClaw — an OpenClaw assistant powered by Nemotron, living inside an OpenShell security sandbox. It remembers, plans, and acts — and none of it ever leaves this device.

What makes this different from chat

Chat answers questions; an agent does work. It keeps memory across conversations, uses tools, runs scheduled tasks, and can be extended with skills — a personal assistant that's always on because the hardware it lives on is always on. The catch with agents is trust: this one runs inside NVIDIA's OpenShell sandbox, so what it can touch is policy, not luck.

Try it live
  1. Open the agent's own interface and just talk to it.
  2. Ask it something with steps: “Plan my demo day: three customer sessions, lunch at noon, and prep time before each.”
  3. Point at the isolation table — it can reason with full GPU power, but it can only touch what the policy allows.

The sandbox, in plain terms
  • Filesystem — reads and writes only inside its own sandbox paths; your files are invisible to it.
  • Network — outbound connections limited to an explicit allowlist; everything else is blocked.
  • Process — no privilege escalation, dangerous syscalls blocked.
  • Inference — model calls rerouted through a controlled endpoint to the local Nemotron.
NVIDIA playbooks on this box
Presenter notes
  • The agent can share a model with chat and other workflows, showing how local AI hardware can serve multiple tasks.
  • No channels (Telegram etc.) are connected on this box by design — nothing external can reach it, and it can't reach out.
  • If the agent seems slow to first reply, the model may be cold-loading; the status line below the button shows sandbox health.
