## Notes for agents

Anything not on this list is an **unpublished pattern**. If several tickets
share a symptom that isn't listed here, escalate to Tier 3 with the affected
asset tags, the common configuration, and any firmware release that plausibly
introduced it. Tier 3 will not accept an escalation without the configuration
evidence.
